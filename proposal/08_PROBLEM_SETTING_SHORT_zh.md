# Problem Setting：个人助理中的权限偏好建模与自适应访问决策

> 2026-09-30 研究问题层次修订。使用 academic-research-suite 与 research-paper-writing；依据用户确认的“可预测性—反馈适应—执行效果”重写正文。RQ 不绑定具体算法，固定可用历史与持续吸收新反馈分别界定；具体方法仅在末段说明实验对应关系。

## 正文草稿

本文考虑个人助理通过工具访问用户数据、完成用户任务的场景。对于涉及特定工具、资源和数据类型的访问请求，用户不仅需要决定是否允许当前访问，还可能表达未来是否希望被再次询问。我们将这类权限回答表示为四种选择：拒绝且不再询问、此次拒绝但下次再问、此次允许但下次再问，以及持续允许。由此，权限自动化所处理的并非单一的允许或拒绝判断，而是同时包含当前访问意愿与后续询问要求的用户偏好。

这些回答为系统理解用户偏好提供了可观察的依据。给定访问上下文和已有的用户历史，系统可以尝试预测尚未观察到的权限回答；当同一用户持续提供反馈时，系统还可以据此更新后续决策。因此，本研究区分两种能力：一是在给定信息条件下预测权限偏好的能力，二是利用新到达的反馈适应该用户的能力。二者的区别不在于是否使用历史信息，而在于持续吸收新反馈是否带来额外的决策收益。这里的连续适应以同一用户为对象，不预设其效果可以直接推广到其他用户。

然而，权限回答预测得更准确，并不必然意味着实际任务中的权限安排更合理。在多步任务中，当前授予的访问范围及其有效期会影响后续的数据访问和询问需求。例如，复用较宽的授权可能减少重复确认，却也可能使后续步骤不再需要的数据继续处于可访问状态；频繁申请狭窄权限则可能增加用户打扰，甚至阻碍任务完成。因此，除了预测和适应用户偏好，系统还需要考虑权限决策的跨步骤后果。本文的核心问题是：如何使个人助理的权限决策适应用户，并在实际授权约束下，取得任务完成、用户打扰与不必要数据暴露之间的合理权衡。偏好预测在其中用于辅助决策，而不替代实际授权。

为评价上述不同层次的能力，我们首先在决策层衡量系统输出与用户回答的一致性，使用四分类准确率／联合精确匹配率（JEM）和 macro-F1 作为主要指标。由于不同错误对访问决策的含义不同，我们同时报告误允许率和错误持续允许率，分别刻画将拒绝误判为允许，以及将未表达持续允许意愿的回答误判为持续允许的风险。在反馈逐步揭示的设置下，进一步考察这些指标随交互轮次的变化，并与不吸收新反馈的匹配对照比较，以识别持续更新带来的适应价值。

决策层的一致性指标无法直接回答任务是否完成、用户被打扰多少次，或实际访问了多少多余信息。因此，在 Agent 执行层，我们通过任务完成率和用户打扰次数衡量效率，并区分实际披露与潜在访问面：前者通过超出当前任务阶段需要的字段读取／发送衡量，后者通过有效授权覆盖的字段数在控制步骤上的累计量衡量。两者均作为隐私暴露的代理指标，而不等同于实际隐私损害；越权执行情况则单独报告。评价时需要联合考察这些指标，因为用户同意访问的数据未必都是任务所必需的，而未完成任务导致的低访问量也不能被解释为更好的隐私—效率权衡。

基于这一设定，本文从权限偏好的可预测性、持续反馈的适应价值，以及动态权限控制的端到端效果三个层次展开研究，具体提出以下问题：

1. **RQ1：权限偏好的可预测性。** 在给定访问上下文与可用用户历史的条件下，自动化权限预测能够达到怎样的偏好一致性和错误允许水平？
2. **RQ2：持续反馈的适应价值。** 在相同初始条件下，相较于不更新的策略，利用同一用户逐步到达的反馈进行更新，能否提高后续权限决策与该用户偏好的吻合程度？
3. **RQ3：动态权限控制的执行效果。** 在相同授权执行约束下，动态调整访问范围与授权生命周期的策略，相较于固定或仅考虑当前请求的策略，能否改善任务完成、用户打扰与不必要数据暴露之间的权衡？

围绕这三个问题，ICL 与经典分类用于建立权限预测基线，MAB 用于考察反馈更新带来的个体化收益，强化学习及 Agent 闭环实验用于检验动态权限管理的执行效果。这些研究层次逐步深入，但其结论分别依赖相应的对照和指标；预测一致性的提高或反馈适应的收益，不能直接替代端到端隐私—效率改善的证据。

## 作者说明（不放入正文）

- 研究主线是“偏好预测 → 用户反馈适应 → 序贯决策与 Agent 执行”，不是预设 ICL、classification、MAB、RL 必然依次更优。DDQN、六动作、ledger／monitor、S-QSTN 和 mock 的内部实现放在 Method／Experimental Setup。
- RQ1 可以使用固定的用户历史，并非无历史或冷启动的同义词；RQ2 识别新反馈更新相对于匹配的不更新对照的增量价值。两者都可涉及个人历史，但比较对象不同。
- RQ3 比较动态权限策略时保持授权执行约束一致。若还要归因 ledger／monitor 等执行组件的作用，应另做组件消融，不能将权限策略与执行约束的同时变化归因于 RL。
- Accuracy 与 JEM 在相同四标签目标和分母下等价。误允许率指真实拒绝样本中预测允许的比例；错误持续允许率指真实标签不为“持续允许”的样本中预测“持续允许”的比例。不要直接等同于 MAB 的通用 over-persistence，后者也涉及持续拒绝。
- 当前 ICL 是 within-user warm-history，分类主结果是 participant-heldout；现有输入特征也不同。可以共同回答论文问题，但不能直接按分数排名。公平比较需要对齐数据、标签、划分、可见信息和反馈条件，或明确分组报告。
- 当前 MAB 是使用问卷标签的反馈回放，不是 Agent 实际执行；其匹配率不能证明任务成功、减少询问或防止数据泄漏。RQ3 的收益仍需端到端证据，不能用前两阶段指标替代。

## 修订核对与来源

写前提纲与写后反向提纲一致：

1. 场景与四类回答（定义对象）：由当前访问意愿引出后续询问要求。
2. 既有历史与新反馈（区分能力）：固定信息下的可预测性与持续更新的额外价值不同。
3. 跨步骤后果（提出总问题）：回答匹配不代表执行安排合理，因而引出任务、打扰和暴露权衡。
