# Survey 引用追溯与研究缺口界定

## 任务边界

基于用户提供的 ACM Computing Surveys PDF，追溯原文中与权限、隐私、用户反馈和执行控制相关的引用。结合已经核对的后续工作，修正 Related Work 对研究缺口的论证。不是完整系统综述，不声称检索穷尽，不改动已同意的 Problem Setting，不运行实验或使用付费 API。

## 工作流程

- [x] 读取 academic-research-suite、PDF、research-paper-writing 和 planning-with-files 相关规则；回顾已同意的问题定义及 Related Work V2。
- [x] 提取并阅读 survey 的相关完整页面，核对元数据、四个 gap、原文引用编号。
- [x] 追溯最相关原论文并核验其方法、评价对象与局限；区分 survey 引用和后续补充文献。
- [x] 对照最接近的工作，形成有边界的缺口判断及“为什么难”的机制解释。
- [x] 写成中文论证稿与可追溯笔记，检查过度新颖性表述、引用和段落逻辑。

## 预先规定的证据标准

1. Survey 提出开放方向不等于证明当前无人研究。
2. 文献中的明确结论、针对本文的综合推断、尚待实验验证的假设分别标注。
3. 动态权限、隐私 RL、个性化权限均不得直接宣称首次提出。
4. 重点检验同一用户持续反馈、授权范围与生命周期的序贯决策，以及匹配执行约束下的任务—打扰—暴露评价。
5. 新正文应把定位和差异融入前部及比较段落，不在末尾再加“本文总结”。

## 错误和降级

- Windows 只读 shell 初次遇到 sandbox ACL 设置错误；使用工具允许的提权只读请求继续，未修改权限或用户系统设置。
- 不把网页检索、元数据匹配或本轮 AI 核对称为用户已亲自阅读或完整系统综述。
