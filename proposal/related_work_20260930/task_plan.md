# Related Work 初稿检索计划

## 目标

依据已确认的 Problem Setting，搜索并核对直接相关文献，必须包含 Wu 等的 S&P 工作；产出可修改的中文 Related Work 初稿与来源记录。

## 范围与阶段

- [x] 确认研究主线、既有证据与技能要求。
- [x] 检索：权限偏好预测／个体适应；反馈学习方法；Agent 权限及运行时约束。
- [x] 核对重点论文原文、出版状态及与本项目的差异。
- [x] 基于证据写中文初稿，区分正文核心文献与方法／背景补充。
- [x] 检查主张与来源对应、措辞和本地链接，交付。

## 决策

- 本次为有针对性的初稿检索，不宣称系统综述或文献覆盖穷尽。
- 以原论文、作者页面、正式会议／出版社页面为证据；预印本明确标注。
- 时间范围：截至 2026-09-30 可核实的工作，并保留相关经典文献。
- 不上传内部稿件、原始参与者数据或密钥；不调用付费模型或服务器。
- RQ1 是固定可用信息下的预测，RQ2 是新反馈的增量价值，RQ3 是权限状态变化的端到端影响。
- 不把我们的实现目标写成已验证收益，不夸大旧工作的缺失。

## 错误与限制

- 本地读取遇到 sandbox helper 启动失败：以同一只读命令申请窄范围提升后成功。
- 技能长文输出截断：已分段补读。
- 部分 PMLR／Now Publishers 页面直开失败：改用可检索的官方页面、作者原稿或正式论文 PDF；不将访问失败误记为已通读。
