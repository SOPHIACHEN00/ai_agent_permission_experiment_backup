# 四标签 ICL：4-shot 与全部历史的小规模配对比较

日期：2026-09-26。4-shot 结果在 [`artifacts/screen_40_seed20260925_4shot_8k_low`](artifacts/screen_40_seed20260925_4shot_8k_low)，原全部历史结果在 [`artifacts/screen_40_seed20260925_8k_low`](artifacts/screen_40_seed20260925_8k_low)。完整配对差值见 [`compare_4shot_vs_full.json`](artifacts/compare_4shot_vs_full.json)。

## 设置

- 复用原实验的 40 位用户、用户内 query 留出第 0 折、599 条测试权限判断、三个模型及生成设置。两轮结果按测试行逐一核对相同。
- 原实验把该用户全部 15–16 个历史 query 放入提示；本轮用固定种子 20260925，从每人的同一训练折随机选 4 个完整 query。一个 query 可包含多条带标签的权限判断。测试 query 的答案始终不在提示中。
- 每模型对 40 位用户各调用一次，共 120 次成功调用。DeepSeek 有一次 JSON 格式错误，保留错误和费用记录后使用相同输入重试成功。

## 结果

| 模型 | 全部历史 Macro-F1 | 4-shot Macro-F1 | 4-shot − 全部历史 | 配对 95% 区间 | 全部历史 / 4-shot Accuracy | 全部历史 / 4-shot 拒绝误判允许率 |
|---|---:|---:|---:|---:|---:|---:|
| Gemini 3.8 Flash | 0.643 | 0.547 | −0.095 | [−0.153, −0.041] | 0.723 / 0.678 | 33.0% / 45.7% |
| GPT-6 Luna | 0.578 | 0.454 | −0.124 | [−0.181, −0.068] | 0.661 / 0.539 | 28.7% / 36.2% |
| DeepSeek V4 Flash 0731 | 0.517 | 0.460 | −0.057 | [−0.115, 0.002] | 0.641 / 0.564 | 42.6% / 51.1% |

三个模型在本次 4-shot 抽样中的 Macro-F1 都低于全部历史。Gemini 的 4-shot Macro-F1 仍是三者最高。区间通过对相同 40 位用户配对重抽样 2,000 次得到；DeepSeek 的 Macro-F1 差值区间跨过 0。拒绝误判允许率在三个模型中也都升高；永久允许误判率、QWK 和其余区间见完整 JSON。

## 费用与解释范围

本轮新增追踪费用 **$0.211928077**，含一次 DeepSeek 格式错误的 **$0.0056332**。连同先前实验，累计追踪费用 **$0.508160718**；未达到 $10 提醒线或 $24 上限。

这是同一批用户、同一留出折上的探索性筛选。4-shot 只采用一个固定随机选例种子，区间反映用户抽样差异，没有覆盖选中哪 4 个 query 所造成的波动。正式结论需要考虑重复选例种子及完整五折；用户内留出成绩也应与整位用户留出的分类实验分开报告。
