# 四标签经典分类器：严格分析报告

> 分析对象：`classification_experiments/artifacts/nested_tuning_20260809`  
> 主证据：`participant_heldout`；`row_stratified` 仅作切分敏感性检查  
> 分析性质：证据整理与决策支持，不是论文式 Results 段落

## 结论先行

- 若只看固定 participant-held-out 测试集的点估计，调参后的 Factored LR 具有最高的 Accuracy（`0.436353`）和 Macro-F1（`0.377619`）；调参后的 Ordinal LR 具有最高的 QWK（`0.317849`）；调参后的 Flat four-class LR 具有最低的过度分享率（`0.425708`）和最低的持续授权过度率（`0.210433`）。因此不存在一个在效用与风险上同时占优的单一模型。
- 三个模型的 Macro-F1 调参增量都很小，而且 2,000 次参与者配对聚类 bootstrap 的 95% CI 均跨过 0：Flat `+0.375` 个百分点 `[-0.196, +0.958]`，Ordinal `+1.148` 个百分点 `[-0.361, +2.656]`，Factored `+1.174` 个百分点 `[-0.403, +2.764]`。当前证据不足以声称调参稳定提高了主指标 Macro-F1。
- Ordinal 与 Factored 的 Accuracy 增量区间不跨 0，但代价明显：Ordinal 的过度分享率增加 `+6.132` 个百分点、持续授权过度率增加 `+5.393` 个百分点；Factored 分别增加 `+10.613` 和 `+3.581` 个百分点，四个风险增量区间均完全高于 0。
- Flat 调参仅产生很小的点估计变化，Accuracy、Macro-F1、QWK 及两项风险指标的 95% CI 都跨过 0。它是当前更保守的默认经典基线，但不能写成“调参已被证明有效”。
- 当前只有一个 outer split seed（`42`）。bootstrap 只反映固定切分下参与者抽样的不确定性，不覆盖切分、训练或超参数选择的全部变异。因此本报告不宣布“最佳模型”或“显著优于”。

## 明确比较问题

1. **主问题**：在同一固定 participant-held-out 测试集上，每种架构的 tuned 版本相对其 baseline 是否提高 Macro-F1？
2. **次问题**：调参对 Accuracy、QWK、过度分享率和持续授权过度率造成什么效用—风险取舍？
3. **模型选择问题**：在 tuned 模型之间，哪一个仅在点估计上领先；这些差异是否足以支持“整体最好”的决策？
4. **切分敏感性问题**：row-stratified 与 participant-held-out 的结果相差多少；包含同一参与者的训练/测试切分是否会给出更乐观的描述性结果？

主指标为 Macro-F1（越高越好）。Accuracy 与 QWK 为辅助效用指标（越高越好）；过度分享率和持续授权过度率为风险指标（越低越好）。

## 数据、样本与推断单位

- 全部数据：`16,361` 行、`201` 名参与者；数据 SHA-256 为 `4a6f61191318eaa79ba2fac1ab80e6fb850e099f1f0178eef2f53b3b527fe463`。
- 主切分：训练 `13,038` 行 / `160` 名参与者；测试 `3,323` 行 / `41` 名参与者；参与者重叠数为 `0`。
- 测试集类别支持数：No, never share `510`；No, but ask me next time `338`；Yes, but ask me next time `1,414`；Yes, always share `1,061`。
- 推断单位：**参与者 cluster**，不是单独的数据行。测试参与者每人有 `68–91` 行，中位数 `82` 行。
- 内层调参：3-fold GroupKFold，以参与者分组；选择指标为 Macro-F1。
- 外层切分只有 seed `42`；bootstrap 使用随机状态 `20260809`，共 `2,000` 次。

## “哪个模型最好”的可支持答案

- **若决策只优化固定测试集 Macro-F1 点估计**：Factored tuned 为 `0.377619`，比 Ordinal tuned 高 `0.003260`，比 Flat tuned 高 `0.006964`。
- **若决策只优化 Accuracy 点估计**：Factored tuned 为 `0.436353`，比 Ordinal tuned 高 `0.009028`，比 Flat tuned 高 `0.027084`。
- **若看顺序一致性 QWK**：Ordinal tuned 最高，为 `0.317849`；Flat tuned 为 `0.315495`；Factored tuned 为 `0.274148`。
- **若风险是硬约束**：Flat tuned 在两项风险率上都最低。相对 Flat tuned，Ordinal tuned 的过度分享率高 `6.250` 个百分点、持续授权过度率高 `8.842` 个百分点；Factored tuned 分别高 `12.146` 和 `1.238` 个百分点。

这些 tuned 模型之间只有点估计比较，没有对应的参与者配对跨模型 CI；因此允许说“点估计最高/最低”，不允许说“整体优于”或“最佳模型已确定”。

row-stratified 测试集包含 `3,273` 行，训练与测试都覆盖全部 `201` 名参与者，参与者重叠为 `201`。participant-held-out 则完全不重叠。下表只比较 tuned 点估计；两种切分的测试行不同，差值不能被解释为纯粹的因果“泄漏效应”。

|---|---:|---:|---:|---:|---:|---:|

## 主结论与风险取舍

1. **默认基线建议**：保留 tuned Flat four-class LR 作为保守的经典分类基线。其点估计略优于自身 baseline，且没有观察到明确的风险恶化；但改进区间均跨 0，因此应把它记录为“当前默认配置”，而不是“已证实提升”。
2. **Ordinal 与 Factored 的定位**：保留为结构化建模的探索分支。它们的 Accuracy 改善与风险恶化同时出现，说明只按 Macro-F1 选择阈值不足以满足权限决策场景。
3. **下一轮调参目标**：把过度分享率和持续授权过度率设为约束或多目标 Pareto 指标，而不是仅作为 Macro-F1 并列后的 tie-break；尤其需要重新扫描 Ordinal/Factored 的决策阈值。
4. **证据升级条件**：运行多个 participant-level outer split seeds 或 grouped nested CV；报告跨 outer run 的均值、标准差与区间；同时补充 tuned 模型之间的参与者配对差值区间。

## Claim Candidates

- **Claim：Factored LR 调参在当前固定 participant-held-out 测试集上提高了 Accuracy，但同时提高了两项权限风险率。**
  - **证据**：Accuracy `+3.039` 个百分点，95% CI `[+1.437, +4.930]`；过度分享率 `+10.613` 个百分点，95% CI `[+7.838, +13.921]`；持续授权过度率 `+3.581` 个百分点，95% CI `[+2.264, +5.035]`。
  - **允许措辞**：在这一固定切分及参与者 cluster-bootstrap 下，Factored 调参表现出 Accuracy 增益与风险恶化的明确取舍。
  - **禁止措辞**：Factored tuned 整体更好、显著优于其他模型、已经适合部署。
  - **不确定性**：Macro-F1 与 QWK 增量 CI 跨 0；只有一个 outer seed；未做 tuned 模型间区间比较。
  - **下一检查**：多 outer seeds 的 grouped nested CV；在风险上限下重新选择阈值。
  - **决策**：**keep**（仅保留为有边界的效用—风险主张）。

- **Claim：Ordinal LR 调参提高了当前固定测试集的 Accuracy，但风险代价大于其 Macro-F1 点估计收益。**
  - **证据**：Accuracy `+2.076` 个百分点，95% CI `[+0.680, +3.457]`；Macro-F1 `+1.148` 个百分点，95% CI `[-0.361, +2.656]`；两项风险分别增加 `+6.132` 与 `+5.393` 个百分点，区间均高于 0。
  - **允许措辞**：Ordinal 调参改变了预测取舍，Accuracy 上升同时伴随更高的过度授权风险。
  - **禁止措辞**：Ordinal 调参稳定改善了分类质量、Ordinal 是最佳顺序模型。
  - **不确定性**：主指标 Macro-F1 的方向未被区间锁定；单 outer seed。
  - **下一检查**：以风险约束或代价敏感效用重新调阈值，并在多切分上验证。
  - **决策**：**weaken**（不保留“整体改善”，仅保留取舍描述）。

- **Claim：Flat four-class LR 的调参效应很小，当前证据没有锁定其改善或恶化方向。**
  - **证据**：Macro-F1 `+0.375` 个百分点，95% CI `[-0.196, +0.958]`；两项风险点估计略降，但区间均跨 0。
  - **允许措辞**：Flat tuned 是一个与 baseline 表现接近、风险点估计未恶化的保守默认配置。
  - **禁止措辞**：Flat 调参有效、Flat tuned 显著优于 baseline、Flat 是最安全模型的普遍结论。
  - **不确定性**：所有调参差值区间均跨 0；只有一个 outer seed。
  - **下一检查**：扩大 C 搜索附近的局部网格，并以多 outer seeds 验证是否值得保留调参复杂度。
  - **决策**：**keep**（作为默认配置记录），**weaken**（关于性能提升的措辞）。

- **Claim：Factored tuned 的 Macro-F1 与 Accuracy 点估计在三个 tuned 模型中最高。**
  - **证据**：Factored tuned 的 Accuracy/Macro-F1 为 `0.436353/0.377619`，Ordinal 为 `0.427325/0.374360`，Flat 为 `0.409269/0.370655`。
  - **允许措辞**：在该固定测试集的点估计中，Factored tuned 排名第一。
  - **禁止措辞**：Factored tuned 统计上优于另外两个模型、Factored 是最佳模型。
  - **不确定性**：没有 tuned 模型之间的配对 bootstrap CI；Factored 的风险率更高，QWK 更低。
  - **下一检查**：补做三种 tuned 模型之间的参与者配对差值区间，并预先定义选择效用函数。
  - **决策**：**weaken**。

- **Claim：模型评价对数据切分方式敏感，row-stratified 结果不应代替未见参与者评价。**
  - **证据**：三种 tuned 模型在 participant-held-out 上的 Accuracy 比 row-stratified 低 `5.372–9.513` 个百分点，Macro-F1 低 `3.313–6.148` 个百分点；row-stratified 的训练/测试参与者重叠为 `201`，held-out 为 `0`。
  - **允许措辞**：本实验的点估计对切分协议敏感；新参与者泛化应以 participant-held-out 为主。
  - **禁止措辞**：所有差距都由数据泄漏造成、row-stratified 结果完全无效。
  - **不确定性**：两种测试集的行组成不同，未通过重复切分分离各因素。
  - **下一检查**：多个 grouped outer splits，并保持可比的类别与参与者分布。
  - **决策**：**keep**。
