# Archived Twin-2K-500 Work

This directory contains the historical Twin-2K-500 materials that were added
for the proposed `Twin persona_summary × old permission-policy card` QSTN
construction. The project has returned to the profile-card V2 path, so these
files are intentionally outside the active implementation tree.

The archive is reversible. The original relative locations are recorded below.
No frozen V1/V2 profile-card source, empirical calibration runner, questionnaire
items, or human-response data were moved.
