# Task Plan: Human-Simulating Questionnaire Agents

## Goal
Identify evidence-backed open-source alternatives to QSTN that minimize manual persona design and can support an RL data-permission training environment.

## Phases
- [x] Phase 1: Scope the decision criteria and inspect local QSTN context.
- [x] Phase 2: Search papers, official repositories, and framework documentation.
- [x] Phase 3: Verify persona provenance, license, maintenance, and RL integration fit.
- [x] Phase 4: Synthesize recommendations and write the research brief.

## Key Questions
1. Which tools include a predefined population/persona catalogue rather than requiring free-form persona authoring?
2. Which tools can produce reproducible, structured questionnaire responses at RL-training scale?
3. What empirical validation is available, and what must still be calibrated with real participant data?

## Decisions Made
- Treat "preset persona" and "automatic demographic-to-persona generation" as distinct capabilities.
- Prefer primary evidence: peer-reviewed paper, official project documentation, and official source repository.
- Evaluate candidates for controlled stochasticity, batch execution, structured actions, population heterogeneity, and license.
