## Baseline findings

- RulePack v1.0 has six grouped runtime rules: P4, P5, P6, partial P9, P10, and P11.
- v1.0 uses no numeric weights, no state schema, and no cross-question memory.
- The evidence-derived skill catalog contains 56 concrete rules and 12 principles.
- Current `questionnaire_items.csv` has 373 items and exposes query, domain, tool, raw data type, generic data type, and necessity status.
- Current questionnaire columns do not explicitly expose requester identity, purpose, expectedness, scope, duration, revocability, review, visibility, explanation, provenance, or prompt burden.
- Current necessity values are 229 `necessary`, 139 `incorrect_explicit`, and 5 `unknown` rows.
- The source processed dataset has participant and query identifiers but no explicit temporal event order or prompt-frequency state that can safely represent longitudinal fatigue.
- Therefore v1.1 must not derive burden, confidence, or context fields from free text, human labels, or population averages.

## Planning implication

The safest v1.1 is a current-turn context and audit extension. It should add explicit schema fields, qualitative completeness buckets, deterministic reason codes, and audit metadata while keeping `state_schema_version=none`. Any prompt modifier that changes the final permission answer should be an explicitly named exploratory mode and should not silently replace the v1.0 baseline.
