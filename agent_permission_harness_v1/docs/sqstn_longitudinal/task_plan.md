## 目标与已确认意图

用户已确认：S-QSTN 使用原来的 `o4-mini` 扮演人类端，同一模拟用户跨多个任务保留适用的交互记忆；DDQN 在连续反馈中真正训练，之后冻结评估。S-QSTN 不是 Personal Assistant 任务 planner，也不是授权内核。目标是学习权限偏好、减少打扰，同时约束不必要的访问。

- 本目录以及设计规格、报告均只留在本地，不同步内部文档到服务器。
- 用户本轮明确给本次完整在线试验分别授权：S-QSTN最多4美元，任务LLM最多5美元，合计最多9美元；两端现均走 OpenAI API，独立记账不互相挪用，旧账本不覆写。
- 不上传原始人类参与者数据、内部笔记或整份 `.env`；小测试使用合成用户及合成任务内容。仅所需Key在调用进程内注入，不回显、不写文件或命令行参数；OpenRouter Key本轮不用。
- 不修改无关文件，不提交 Git，不自动重试失败的付费调用。
- 长期记忆不是永久授权；偏好预测不能生成或扩大实际授权。
